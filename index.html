Como obter a chave grátis do Resend em 1 minuto:

  1. Acesse o site resend.com e crie uma conta gratuita com seu e-mail.
  2. No menu lateral, clique em API Keys e em seguida Create API Key.
  3. Copie a chave que começa com re_... e cole no campo acima.
  4. Pronto! O TaskFlow já enviará os e-mails reais de verificação para qualquer colaborador.
